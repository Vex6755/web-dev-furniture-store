# WEB DEVS — Responsive Furniture Portfolio

An interactive, modular company web platform designed to showcase high-end exhibition furniture and design projects.

## Project Overview
* **Company Name:** WEB DEVS
* **Presentation Date:** October 4, 2026
* **Live Features:** Responsive desktop/mobile drawer navigation, interactive contact form, native phone dialer links, mailbox routing redirects, and an on-demand video media player modal.

## Team Contribution & Modular Architecture
To ensure collaborative version control and independent file tracking, our team split the workload into three distinct modules:

1. **Member 1 (Structure & Content):** Built the foundational HTML5 semantic markup (`index.html`) using semantic, accessible HTML5 markup boxes, and managed remote cloud-hosted media assets.
2. **Member 2 (Layout & Aesthetics):** Engineered the CSS3 visual styling, responsive grids, and mobile viewport media queries (`style.css`).
3. **Member 3 (Interactions & Functionality):** Programmed the Vanilla JavaScript state controllers for the hamburger drawer and video modal behavior (`script.js`).
